1. Executive Overview & Design Philosophy

VOISShield is an intelligent enterprise human-firewall platform designed for threat simulations, automated micro-learning, employee engagement scoring, and security analytics.

Core Architectural Standards:

  • Dual-Theme Parity: Strict 1:1 color token mirroring between Light Mode (Ceramic & Slate) and Dark Mode (Obsidian & Charcoal).
  • Interlocking Bento Grids (L-Containers): Multi-tier cards connected with mathematical bezier fillets (r = 16px) for structured telemetry clustering without gaps.
  • Proportional Normalized Zoom: Global canvas scaling locked via VarHomeScreenScale = 0.92 to maintain unified dashboard geometry on standard laptops and widescreen monitors.

9. Developer Rules & Global Scale Constants

All developers must modify canvas scale through the top configuration variables:

export const VarHomeScreenScale = 0.92;     // Scales entire Dashboard canvas
export const VarSection2HeightAdjuster = 1.30;  // Controls Section 2 vertical stretch
export const VarFadedStepDiscScale = 0.85;    // Scales 3D Quick Access button ripples
export const VarLandingPageScale = 1.00;     // Controls Landing Page presentation scale

Strict Engineering Rules:

  • Locked Heights: The main dashboard column heights are strictly locked (h-[645px]) so sidebar expansion only resizes width, never height.
  • Text Truncation: All dynamic metadata text within sub-cards must include truncate and min-w-0 on parent flex wrappers to prevent horizontal layout blowout.
  • Theme Initialization: The app defaults to Light Mode. Never read prefers-color-scheme without evaluating localStorage.getItem('theme') first.

10. Consistent L-Shaped Bento Containers & Interlocking Isolated Modules

In V2.0, the entire layout architecture is unified around Interlocking L-Shaped Bento Hosts coupled with complementary Combo Isolated Pieces. Rather than using conventional uniform rectangular grids, each analytical module uses an asymmetrical L-bracket container that cradles a standalone, high-salience isolated trigger block.

Core Architectural Principles of the L-Shape Bento Combo:

  • Global App Consistency: Every major sub-system (Campaign Triggering, Scoring Matrices, Telemetry Drills, and Simulation Execution) is encapsulated within an L-shaped host paired with a dedicated isolated block.
  • The Combo Isolated Piece: A high-contrast, self-contained sub-card (e.g., event definitions, trigger state pills, badges) docked into the cut-out corner of the L-container. It signals context while the L-container provides metrics and actionable controls.
  • Zero-Dead-Zone Docking: The inner cut-out corner and outer corner of the host container match the corner radius of the isolated component (radius = 16px to 20px), ensuring perfect visual cohesion.
  • Multi-Quadrant Flexibility: The L-geometry is invertible across four quadrants (Top-Left, Bottom-Right, Top-Right, Bottom-Left) depending on reading order and data priority.
